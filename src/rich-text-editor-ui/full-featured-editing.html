This sample demonstrates the Rich Text Editor UI with Slash Command support enabled. The Slash Command feature allows users to quickly access editing actions and content insertion options by typing / within the editor. The editor provides a rich set of formatting tools through its toolbar, enabling users to create and edit content while generating valid HTML markup. The editor's toolbar includes tools for formatting and managing content.

  • Lists - NumberFormatList and BulletFormatList types.
  • Links - A hyperlink can be inserted into the editor for quick access to related information.
  • Image - Inserts and manages images.
  • Table - Inserts and manages tables.
  • Alignment - Aligns the content with left, center, and right margins.
  • Undo/Redo - Allows undo and redo operations.
  • Font - Provides text styling options such as font family, font size, font color, and background color.
  • Formats - Applies predefined text formats such as paragraphs and headings.
  • Bold / Italic / Underline / Strikethrough - Applies inline text formatting to the selected content.
  • Subscript / Superscript - Formats the selected text as subscript (lower) or superscript (upper).
  • Slash Command - Allows users to quickly access editor commands and content insertion options by typing / within the editor.
