This sample demonstrates the default formatting features of the Headless Editor.

The Headless Editor provides a lightweight and flexible editing experience with commonly used text and block formatting options.

Key features demonstrated in this sample:

  • Text formatting with Bold, Italic, Underline, Strikethrough, and Code.
  • Block formatting through the Format menu.
  • Insertion of Horizontal Rules and Block Quotes.
  • Support for Bullet Lists and Numbered Lists.
