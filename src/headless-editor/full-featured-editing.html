This sample demonstrates the features of the Headless Editor. It showcases rich text formatting, block content editing, list, links, tables, images, and advanced content editing capabilities.

      The Headless Editor is a framework-independent rich text editing that provides a flexible set of APIs for creating and managing structured content. It supports text formatting, block content, lists,links, tables, images, and advanced content blocks.

      Key features demonstrated in this sample:

      • Text formatting including Bold, Italic,Underline, Strikethrough, Code,Superscript, and Subscript.
      • Font customization with Font Family, Font Size,Text Color, and Highlight Color.
      • Block formatting with Headings, Paragraphs,Block Quotes, Code Blocks, andHorizontal Rules.
      • Lists including Bullet, Numbered, andTask Lists, with indentation, nesting, splitting, joining, deletion, and list style customization.
      • Link management with support for Adding,Updating, and Removing links.
      • Table editing with support for inserting and deletingRows, Columns, and Tables, along with Header Rows, Header Columns,and Cell Attributes.
      • Image management including Insert, Update,Delete, Resize, Alignment, Wrapping, Display Options, and Captions.
      • Advanced content blocks including Callouts and Collapsible Content.
      • Editing history with Undo and Redo.
      • Keyboard navigation and Keyboard Shortcuts for efficient editing workflows.
      • Content handling with Paste and Input Rules.
