This sample demonstrates a product catalog built using the Syncfusion® Javascript Data Grid with column templates and a detail template. Each row displays product information through customized templates, including product details, sales trends, pricing, and stock status.

The Syncfusion® JavaScript Data Grid demonstrates the use of detail and column templates to display product inventory. Custom templates are applied to columns such as "Product", "Sales", and "Status".

Rows can be expanded to display a detail section using the Syncfusion® Card layout. This section presents product information including detailed descriptions, specifications, and pricing details.

More information on the Grid detail template feature can be found in the detail template documentation.
