This sample demonstrates the Syncfusion AI AssistView component as a Chart Assist solution. Enter natural-language instructions to create, visualize, modify, analyze, export, or print charts. The assistant generates interactive chart previews, configuration updates, and complete TypeScript code directly within the conversation.

The Chart Assist experience enables users to create and edit charts using natural-language prompts. The AI AssistView component interprets user requests and returns structured ChartConfig objects that are rendered as interactive chart visualizations.

Responses are organized into generative blocks that provide explanations, configuration change summaries, generated TypeScript code, and live chart previews. The registered chart-tool dynamically renders either Chart or AccumulationChart based on the generated chartType.

Users can generate charts from scratch, change chart types, update data points, add annotations, apply strip lines, configure technical indicators, and enable interactive features such as tooltips, crosshairs, zooming, selection, and highlighting. Generated charts can also be exported in multiple formats or printed directly from the interface.

Session-based chat history allows users to revisit previous chart conversations and continue refining existing visualizations. Restored sessions automatically rebuild associated chart previews while preserving the full interaction history.

Injecting modules

Chart functionality is organized into feature modules. The sample dynamically injects the required chart series, axis, interaction, annotation, indicator, and export modules based on the generated chart configuration. This ensures that generated charts are rendered correctly without requiring manual configuration.
