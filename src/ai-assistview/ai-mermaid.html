This sample demonstrates the integration of the AI AssistView with Mermaid diagram rendering. The generated Mermaid diagrams are rendered directly within the response for visualizations.

In this example, the bannerTemplate customizes the banner content, and toolbarSettings adds a right-aligned Refresh button. The promptSuggestions provide quick-start diagram examples, and promptRequest handles user prompts using a system prompt that guides AI responses. The sample generates Mermaid diagram code and renders it using the Mermaid library, supporting six diagram types: Flowchart, Sequence Diagram, Class Diagram, State Diagram, Entity-Relationship Diagram, and XY Chart.
